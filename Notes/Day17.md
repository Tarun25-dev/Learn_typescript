#### readonly

- readonly property in object types.
```ts
type User = {
    name: string;
    readonly id: number;
};
let user1: User = {
    name: "Tharun",
    id:3225
};

```
- id can be read but it can't be changed/reassigned/modified/delete

**Why use readonly?**
- Imagine an object contains an ID generated by your application:
```ts
type User={
    readonly id: number;
    name: string;
};
```
- Once the user is created we dont want some code accidentally doing to that id like user.id = 999.
```ts
let user: User={
    id:101,
    name: "tharun"
};
```
- readonly to ts: This property can be read, but don't allow code to modify it.
- readonlt is a typescript compile time restriction.
- Its main purpose is to let typescript catch accidental modifiactions while you're writing/compiling typescript code.
